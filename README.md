# Marketplace

Facebook Marketplace clone: Next.js 15, React 19, Tailwind CSS 3, shadcn/ui-style components, Supabase.

## Setup
1. `npm install`
2. Run `supabase-schema.sql` in the Supabase SQL Editor (safe to re-run).
3. `.env.local` and fill with your SUPABASE API URL = `NEXT_PUBLIC_SUPABASE_URL` (project URL, no path) and `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. `npm run dev`, then restart it whenever `.env.local` changes.
